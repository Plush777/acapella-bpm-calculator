# 아카펠라 박자 계산기

반주 위에 아카펠라를 얹어 리믹스할 때, 아카펠라 길이를 몇 퍼센트로 조절해야 반주와 박자가 맞는지 계산하는 웹 도구입니다.

**배포 주소: https://acapella-bpm-calculator.onrender.com**

## 이런 때 사용합니다

반주는 67 BPM인데 아카펠라는 73 BPM이라면, 그대로 얹었을 때 아카펠라가 점점 앞서갑니다. 이 도구에 두 BPM을 입력하면 아카펠라를 108.96%로 늘려야 한다는 것과, 늘리지 않으면 8마디 뒤에 2.36초가 어긋난다는 것을 알 수 있습니다.

## 기능

| 기능 | 설명 |
|---|---|
| 길이 비율 계산 | 두 BPM으로 아카펠라를 얼마나 늘리거나 줄일지 계산하고, 결과를 복사할 수 있습니다. |
| BPM 측정 | 음악을 들으면서 박자에 맞춰 버튼을 누르면 BPM을 측정합니다. |
| 아카펠라 BPM 변경 | 아카펠라 BPM을 절반이나 2배로 바꿉니다. |
| 조절 후 길이 | 아카펠라의 원본 길이를 입력하면 조절한 뒤의 길이를 보여 줍니다. |
| 박자 차이 확인 | 원본을 그대로 썼을 때 뒤로 갈수록 얼마나 어긋나는지 그래프와 표로 보여 줍니다. |
| 메트로놈으로 듣기 | 그래프로 본 박자 차이를 소리로 들려줍니다. |

입력한 값은 사용 중인 브라우저에 저장되어 다음에 열어도 그대로 남아 있습니다.

## 사용 방법

### 1. BPM 입력하기

1. **반주 BPM**과 **아카펠라 BPM**을 입력합니다. 20부터 400까지 입력할 수 있습니다.
2. BPM을 모르면 음악을 들으면서 박자에 맞춰 **BPM 측정** 버튼을 4번 이상 누릅니다. 여러 번 누를수록 정확합니다.
3. 곡의 **박자**를 4/4와 3/4 중에서 고릅니다.

아카펠라는 드럼이 없어 박자를 세기 어려우니, 아카펠라가 나온 원곡을 들으면서 측정하는 것이 좋습니다.

BPM 분석 프로그램은 70 BPM인 곡을 140 BPM으로 알려 주기도 합니다. 결과가 이상하면 **아카펠라 BPM 변경**의 **절반으로**나 **2배로** 버튼을 눌러 보세요.

### 2. 아카펠라 길이 조절하기

**아카펠라 길이 비율**에 나온 값을 사용하는 프로그램에 입력합니다. 속도를 바꾸지 않은 원본에 적용해야 합니다.

Cakewalk에서는 다음 순서로 적용합니다.

1. 프로젝트 템포를 반주 BPM으로 맞춥니다.
2. 아카펠라 클립을 선택하고 <kbd>Shift</kbd> <kbd>I</kbd> 키를 함께 누릅니다.
3. AudioSnap 항목의 **Stretch Amount**에 길이 비율을 입력합니다.

길이 대신 속도를 입력하는 프로그램이라면 **재생 속도** 값을 사용합니다.

### 3. 박자 차이 확인하기

1. **확인할 구간**을 고릅니다.
2. 그래프에서 세 줄의 마디선을 비교합니다. 맨 위가 아카펠라 원본, 가운데가 반주, 맨 아래가 길이를 조절한 아카펠라입니다.
3. 구간별로 어긋나는 시간과 박자는 아래 표에서 확인합니다.

### 4. 메트로놈으로 듣기

1. **재생할 아카펠라**를 **길이 조절 후**와 **원본** 중에서 고릅니다.
2. **메트로놈 재생** 버튼을 누릅니다. 왼쪽에서 반주, 오른쪽에서 아카펠라의 박자가 들립니다. 이어폰으로 들으면 구분하기 쉽습니다.

**길이 조절 후**를 고르면 두 소리가 끝까지 겹치고, **원본**을 고르면 점점 벌어집니다. 실제 음원이 아니라 입력한 BPM으로 만든 메트로놈 소리입니다.

## 알아 두면 좋은 점

- 두 곡의 BPM이 처음부터 끝까지 일정하다고 보고 계산합니다.
- 길이를 맞춰도 아카펠라가 들어오는 위치는 직접 들으면서 맞춰야 합니다.
- 짧은 구간은 원본을 그대로 써도 괜찮지만, 긴 구간은 처음과 중간, 끝을 모두 들어 보는 것이 좋습니다.

## 계산 방법

```text
길이 비율(%) = 아카펠라 BPM / 반주 BPM * 100
재생 속도(배) = 반주 BPM / 아카펠라 BPM
구간 시간(초) = 마디 수 * 한 마디의 박 수 * 60 / BPM
```

## 실행 방법

설치하거나 빌드할 것이 없습니다. ES6 모듈을 사용하므로 `index.html`을 더블클릭해서 열면 동작하지 않고, 로컬 서버로 열어야 합니다.

```bash
python -m http.server 8000
```

실행한 뒤 브라우저에서 `http://localhost:8000`으로 접속합니다.
