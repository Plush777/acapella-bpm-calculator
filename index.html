아카펠라 박자 계산기

반주와 아카펠라의 BPM을 넣으면 보컬을 몇 %로 늘리거나 줄일지, 클립을 어디에 놓을지 계산합니다. 길이 비율과 위치 표기는 Cakewalk Sonar 기준입니다.

계산기를 불러오지 못했습니다. 파일을 직접 여는 대신 웹 호스팅이나 로컬 서버 주소로 열어 주세요.

드럼이 있는 원곡을 들으며 박마다 버튼을 누르면 BPM이 채워집니다.
